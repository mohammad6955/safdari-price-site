SAFDARI PRICE SITE
=================

اجرای ویندوز:
1) Python 3.11 یا جدیدتر نصب باشد.
2) داخل همین پوشه CMD/PowerShell باز کن.
3) دستورها:
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python app.py
4) مرورگر:
   http://127.0.0.1:5000
5) پنل مدیریت:
   http://127.0.0.1:5000/admin
   رمز پیش‌فرض: 1234

مهم:
- قبل از انتقال به هاست، ADMIN_PASSWORD و SECRET_KEY را به متغیر محیطی امن تغییر بده.
- فایل safdari.db بعد از اولین اجرا ساخته می‌شود.
- عکس‌ها داخل static/uploads ذخیره می‌شوند.
- قیمت مدل از نسبت قیمت مرجع مدل به قیمت طلای مرجع محاسبه می‌شود.
- برای هر مدل می‌توانی قیمت طلای مرجع متفاوت ثبت کنی.

فرمول:
قیمت فعلی مدل = قیمت مرجع مدل × (قیمت طلای فعلی ÷ قیمت طلای مرجع مدل)

این نسخه برای شروع آماده است؛ برای انتشار عمومی، HTTPS و سرور production استفاده شود.
